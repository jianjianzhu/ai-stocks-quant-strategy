# SMC V6 策略回测版

基于 LuxAlgo 的 [Smart Money Concepts (SMC)](https://www.tradingview.com/script/CnB3fSph-Smart-Money-Concepts-SMC-LuxAlgo/) 修改，保留 **CC BY-NC-SA 4.0**，详见 [许可说明](LICENSE.md)。本目录不适用仓库根目录的 MIT 许可证。

## 使用方法

1. 在 TradingView 打开标准蜡烛图，选择品种和周期。
2. 打开 Pine Editor，新建脚本，粘贴 [SMC_V6_strategy.pine](SMC_V6_strategy.pine) 全部内容。
3. 保存并添加到图表，打开 Strategy Tester 查看交易记录。
4. 设置回测起止时间，在策略属性中核对资金、仓位、佣金和滑点。

这是 Pine Script v5 策略；V6 是本项目版本号。它独立运行于 TradingView，尚未与本仓库 Python 回测或 Alpaca 实盘脚本连接。

## 策略行为

- 仅做多；试买使用内部看涨 CHoCH，普通买入使用内部看涨 BOS，强买使用摆动级别看涨 BOS/CHoCH 与内部多头结构。
- 入场结合 EMA 过滤，可选择成交量过滤；信号在 K 线收盘确认。
- 内部看跌 CHoCH 可触发一次部分减仓；摆动级别看跌结构或超出回测结束时间可触发平仓。
- 使用 ATR 初始止损，可选择保本与移动止损；退出后设有再入场等待期。
- 保留结构、订单块、FVG、等高等低与前期高低点的可视化功能。

## 默认参数

| 参数 | 默认值 |
| --- | --- |
| 初始资金 | 100,000 USD |
| 每次入场 | 100% 权益，无加仓 |
| 佣金 | 每次成交金额的 0.10% |
| 滑点 | 1 tick |
| EMA | 20 / 50 / 200 |
| ATR 初始止损 | ATR(14) × 2 |
| 减仓比例 | 50% |
| 保本 / 移动止损 | 默认关闭 |

试买、买入、强买是信号分类，当前默认仓位大小相同。默认仓位仅是脚本配置，并非仓位建议。

## 验证状态与已知限制

本次发布保持上午 V6 的可执行代码原样，仅增加来源和修改说明。发布时完成 UTF-8、代码一致性与文档链接检查，未在本次发布流程中执行 TradingView 编译或回测，不提供未经验证的收益率。

- 枢轴和历史结构标记可能画在较早的 K 线上，不能把标记位置当作当时已知的交易信号。
- 脚本包含多周期数据和独立持仓状态，仍需使用 Bar Replay、实际成交记录与不同品种周期验证。
- 保本/移动止损更新内部价格后，没有在同一代码分支立即重新提交对应的 `strategy.exit`；模拟器止损订单可能比内部状态晚更新。启用这些选项前需专项验证，不能将图上的止损线等同于实际成交。
- 信号参考入场价为收盘价；模拟器成交受滑点和费用影响，保本参考价并不保证净收益为零。
- 保留了原脚本的 `alertcondition` 调用；策略告警应单独验证，不应假定与指标告警行为一致。
